Cleaner runtime warnings and reworked documentation. No change in what is scanned or shipped.

* **Shorter prep-step warnings.** The Maven, Gradle and .NET warnings printed to the console and `depminer.log` now state only what you lose and how to fix it, without example measurements.
* **Reworked documentation site.** Each page now leads with what you need to do; the prep guide is organised by language, and .NET is listed among the ecosystems that need a one-time prep step.
* **Latest by default.** The `voyenv.yml` example no longer pins a DepMiner version; `voyenv` installs the newest release, and a comment shows how to pin one.

Pinned tool versions: Syft 1.46.0, Trivy 0.72.0.
